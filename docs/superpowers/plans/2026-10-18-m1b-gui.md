# GUI (design §8) Implementation Plan

**Goal:** The one-window GUI from the design: drop EPUBs → rows with cover, title, author, series, mode badge → Send to Kindle / Export to folder with per-row stage progress → results; settings drawer; device bar. Wired to the M1 pipeline. M2+ features (X-Ray, Word Wise, LLM, Amazon match, MTP) are visible but disabled with the reason.

**Spec:** docs/superpowers/specs/2026-10-18-deckle-design.md §8 (and §5 for the badge).

## Tasks
1. `deckle-core::pipeline::run_with_progress(epub, opts, on_stage)` — stage callback (TDD with the fake Previewer). `run` delegates to it.
2. Tauri commands (`apps/desktop/src-tauri/src/commands.rs`): `expand_epub_paths`, `inspect_books` (cover as data URL), `list_devices`, `previewer_status`, `get_settings`/`set_settings` (JSON in app config dir), `run_books` (thread, emits `book-progress`), `reveal`. Pure parts unit-tested; CLI args / `DECKLE_OPEN` preload books.
3. Frontend: `BookList`/`BookRow` (badge, progress, menu: prefer features/cover, show report, remove), `BottomBar` (devices, target picker, Send, Export…), `SettingsDrawer`, drag-drop + Add books dialog.
4. Visual check: screenshot with preloaded books and a completed send; commit.
