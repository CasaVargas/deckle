# The Morgue Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Keep every Deckle Daily edition in a plain folder with a searchable sidecar, show it
on the Daily tab as a month of front pages, and let any edition be sent to the Kindle again.

**Architecture:**
- **A new crate, `crates/deckle-morgue`,** owns the folder: sidecars, archive, import,
  retention, search and detail.
- **The CLI** archives every built and converted edition. It answers `digest morgue
  list|search|show|send`, and records deliveries, highlight counts and Kindle presence at each
  connection in `morgue.json`.
- **`deckle_core::queue::Prune`** gains an exemption list, so a re-sent edition survives
  `keep = 3` for 7 days.
- **The desktop app** reads through Tauri commands, and sends by running the bundled CLI the
  way the Build and Send buttons already do.

**Tech Stack:**
- Rust 2024 workspace: `deckle-digest` (Edition), `deckle-readership` (reads), `zip` (reading
  imported EPUBs), `serde_json`, `deunicode` (accent folding, already a workspace dependency).
- Tauri 2, React/TS, vitest.

**Spec:** `docs/superpowers/specs/2026-10-22-morgue-design.md`

## Global Constraints

- **Folder:** default `~/Deckle/Morgue`; `[morgue] folder` in `digest.toml`, with `~` expanded
  like `[reading] inbox` (`deckle_digest::inbox::expand_home`).
- **Layout:** `YYYY/YYYY-MM-DD.epub`, `YYYY/YYYY-MM-DD.json`, `YYYY/YYYY-MM-DD.kfx`.
- **Retention:** `keep_days = 365` by default, `0` keeps everything. KFX copies are kept 14
  days. Only files named `YYYY-MM-DD.{epub,json,kfx}` inside `YYYY/` folders are ever deleted.
- **Sidecar:** the fields of spec §4, exactly. Each story's `text` is plain text with
  whitespace collapsed, capped at 20,000 characters.
- **No database, no index.** Search scans the sidecars in memory. 365 sidecars take under 1 s
  in a release build.
- **Search:** case- and accent-insensitive, and every query word must match (AND) across
  `title`, `teaser` and `text`. Results come newest first, grouped by edition. An empty query
  returns nothing.
- **Send again:** queue the kept KFX, or convert from the EPUB when the KFX is gone. The name
  is `deckle-daily-YYYY-MM-DD.kfx`. Prune skips it for 7 days after delivery.
- **State:** `morgue.json` next to `digest.toml`. Writes go through a temp file and a rename
  everywhere.
- **Archiving never fails a build.** An error becomes a run note: "Morgue: couldn't save the
  edition (…)".
- **Exact copy:**
  - "Weekday, Month D · No. N";
  - "You read about N%, to <section>", or "Not opened";
  - "N passages highlighted";
  - "On the Kindle" / "No longer on the Kindle";
  - the buttons **Send again**, **Open**, **Show in Finder**;
  - the card title **Every edition**;
  - the size line "Morgue: N editions, M MB".
- The pre-push hook runs fmt and clippy `-D warnings`. Keep them clean.

**Plan rulings** (the spec's sources don't exist as written; flagged to the owner):

- **Highlight counts.** `highlights.json` stores entry ids without dates, so it can't count
  per edition. Instead, whenever a connection reads `My Clippings.txt`, the CLI counts that
  edition's highlights per date (`deckle_highlights::book::edition_date`) into
  `morgue.json.highlights`. The detail line shows when a count is known.
- **"On the Kindle".** At each connection with readership positions, the CLI records each
  stem's presence from `flush.positions` (`OnDevice::Absent` means gone) into
  `morgue.json.on_kindle`. Editions not in that list show no presence line.
- **The desktop's Send again** runs `deckle digest morgue send <date> --json` through the
  bundled CLI, like `daily_run`, so the Previewer fallback lives in one place.

## Review Focus

1. **The Morgue folder can't be written** (iCloud offline, permissions, a full disk). The
   build still succeeds, the note says why, and nothing half-written is left as
   `YYYY-MM-DD.json`. Test in Task 2.
2. **The same date built twice** (a manual Build after the morning run). One edition with the
   newer files; search shows it once. Test in Task 2.
3. **Files you put in the Morgue yourself** (notes, renamed copies, a `2025/old.epub`) are
   never deleted or listed as editions. Test in Task 2.
4. **Send again with no Kindle connected.** The edition waits in the outbox and survives
   until delivery. The 7-day clock starts at delivery, not at queueing. Test in Task 6.
5. **Queries with punctuation and diacritics** ("café's", "mill—brewery", "  "). Words are
   split on non-letters and folded, and blank queries find nothing. Test in Task 4.
