# Portable conformance fixtures

The JSON fixtures and `cases.json` in this directory are offered under the MIT
license below for independent compatible-client implementations. `valid` records
schema acceptance; `runtime_valid`, when present, records additional normalized
URL identity checks that JSON Schema exact-string uniqueness cannot express.
