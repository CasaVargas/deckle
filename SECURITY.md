# Security

## Reporting a problem

Please don't open a public issue for a security problem. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/CasaVargas/deckle/security/advisories/new)
instead. You'll get a reply there, and the fix and advisory are published once a release has it.

Useful to include: the Deckle version, your OS, what an attacker can do, and the steps to
reproduce it.

## Supported versions

Fixes go into the latest release. Deckle updates itself, so please update before reporting.
